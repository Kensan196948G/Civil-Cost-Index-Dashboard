# AI拡張ロードマップ｜Civil Cost Intelligence Dashboard

本書は、Civil Cost Index Dashboard を「建設コストの可視化」から「監視・説明・予兆検知・影響分析・意思決定支援」へ進化させるAI拡張の全体構想と段階導入計画を定める。要件上の正式スコープは要件定義書 第11章「AI拡張要件」、Phase 1 の実装詳細は詳細設計仕様書 第16章を参照。

## 推奨原則（全Phase共通）

- 集計・計算・予測値はコードで生成し、AIは説明・検索・要約を担当する
- 回答には必ず出典と基準年月を付け、AIが参照した系列を表示する
- データ不足時は推測せず「判断不能」とする
- AI回答を積算・契約判断の確定値にしない
- AI出力を保存し再現可能にする（監査ログ）
- モデルを後から変更できるプロバイダー抽象化を設ける

## 画面構成（目標）

| 画面 | 主な機能 | 状態 |
| --- | --- | --- |
| AI市況ナビ（`/ai`） | 今月の要約、注目変動、確認事項 | ✅ Phase 1 実装済み |
| AI管理（`/admin/ai`） | データ品質、取込異常、監査、費用 | ✅ Phase 1 一部実装済み |
| AI分析 | 自然言語検索、グラフ対話、比較 | Phase 3 |
| 予測・シナリオ | 3〜12か月予測、影響試算 | Phase 4（案件影響試算は ✅ 実装済み） |

## Phase 1：AI市況ナビ（実装済み）

- ✅ AI月次サマリー（対象者別文章変換: 経営層／積算／発注者）
- ✅ アラート説明（判定はルール、説明はAI）
- ✅ AIレポート生成（Markdown・出典・免責自動添付）
- ✅ AI分析テンプレート
- ✅ データ品質支援（更新遅延・欠損・固定値・Zスコア外れ値・表記揺れ候補・品質スコア）
- ✅ AI監査ログ・フィードバック収集

## Phase 2：AIデータ品質

- 表記揺れ統合の承認UI（「異形棒鋼 SD295A」と「鉄筋 SD295A」は同一品目候補です。統合しますか？）
- 地域名の自動マッピング候補・単位不一致検出・年月形式の推定
- CSV列の自動対応付け・PDF/Excel表の構造推定
- データソース形式変更検知（列名追加・ヘッダー位置変更・基準年変更などの説明）
- 取込失敗原因の要約・エラー行の分類・修正方法の提案（AI管理者アシスタント）

## Phase 3：対話分析・RAG

- 自然言語によるデータ検索（質問を `/api/timeseries` `/api/compare` `/api/alerts` の安全なパラメータへ変換。AIによるSQL生成・実行は行わない）
- グラフ対話分析（AIへの入力は画面表示中の系列に限定）
- 根拠付きAIチャット／RAG（国交省公表資料・e-Stat定義・取込履歴・用語集などを検索対象に、Neon pgvector でベクトル検索。回答には参照資料・データ年月を必ず付ける）
- 関連系列の自動発見（相関・時差相関・代替資材候補。「相関＝原因」ではないことを明記）

## Phase 4：予測・案件影響

- 短期予測（3・6・12か月の参考レンジ: 中央予測・上下限・信頼区間・データ不足警告。「確定予測」ではなく「参考シナリオ」）
- 複数シナリオ予測（基準／上振れ／下振れ／ストレス／利用者設定。計算は再現可能な数式、AIは説明のみ）
- ✅ 工事案件別コスト影響シミュレーション（数量×単価差の影響額試算。`/projects`・`POST /api/projects/{id}/simulate`。AI説明文生成は未）
- AI概算補正係数（採用指数・重み・計算式・出典・「人による確定」を必須表示）
- 類似工事・工種別影響分析（匿名化・集計化した構成比から開始）
- 先行指標候補の探索（為替・原油・輸入物価など）

## 継続検討（Phase横断）

- パーソナライズされたAI通知・AIウォッチリスト
- 通知チャネル拡張（メール・Teams・Slack）
- AIフィードバックの品質評価への活用（即時自動学習は行わず、プロンプト・ルール・評価データの改善材料として管理）
- AI費用・使用量の可視化
